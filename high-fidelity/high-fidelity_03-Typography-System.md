# 5. Typography Scale

EduCore uses a controlled scale [cite: 3]. Avoid arbitrary sizes [cite: 3].

- **Display:** Major product moments (login welcome, onboarding). *Usage: Rare.* [cite: 3]
- **Heading 1:** Page-level titles (e.g., *Student Management*) [cite: 3].
- **Heading 2:** Major sections (e.g., *Attendance Summary*) [cite: 3].
- **Heading 3:** Subsections (e.g., *Payment History*) [cite: 3].
- **Body Large:** Important descriptive text, dashboard explanations [cite: 3].
- **Body:** Default application text used for descriptions, labels, and instructions [cite: 3].
- **Small Text:** Supporting information (timestamps, metadata, hints) [cite: 3].
- **Caption:** Lowest emphasis (helper text, additional context) [cite: 3].

---

# 6. Typography Hierarchy Example

- **Poor hierarchy:** Student / Adebayo Daniel / JSS 1A / Active *(Everything looks equal)* [cite: 3].
- **Better:** 
  - **Adebayo Daniel** *(Student Profile)* [cite: 3]
  - **Admission Number:** `GIA/26/0001` [cite: 3]
  - **Class:** `JSS 1A` [cite: 3]
  - **Status:** `Active` *(Clear importance)* [cite: 3]

# 7. Heading Rules

Headings should [cite: 3]:
- describe purpose [cite: 3]
- be concise [cite: 3]
- avoid unnecessary capitalization [cite: 3]

- **Preferred:** *Student records* [cite: 3]
- **Avoid:** *STUDENT RECORD MANAGEMENT SYSTEM* [cite: 3]

---

# 8. Text Alignment Rules

- **Default:** Left aligned [cite: 3].
- **Center alignment:** Use only for empty states, authentication screens, and focused messages [cite: 3].
- **Avoid:** Centering operational data [cite: 3].

---

# 9. Table Typography

Tables are critical in EduCore [cite: 3].

- **Headers:** Clear distinction [cite: 3].
- **Data:** Optimized for scanning [cite: 3].
- **Avoid:** Large decorative text inside tables [cite: 3].

---

# 10. Numbers and Financial Data

Numbers require special treatment (fees, attendance percentage, scores) [cite: 3].

- **Important numbers:** Larger size, stronger weight [cite: 3].
- **Supporting numbers:** Normal text [cite: 3].

---

# 11. Font Weight Rules

Avoid excessive weights [cite: 3].

- **Regular:** Body text [cite: 3]
- **Medium:** Labels, navigation [cite: 3]
- **Semibold:** Headings, important values [cite: 3]
- **Bold:** Rare emphasis only [cite: 3]

---

# 12. Text Color Hierarchy

Not all text should have equal emphasis [cite: 3]:

- **Primary:** Main information [cite: 3].
- **Secondary:** Supporting details [cite: 3].
- **Muted:** Metadata [cite: 3].

---

# 13. Form Typography

Forms should communicate field purpose, requirements, and validation clearly, avoiding unclear labels [cite: 3].

---

# 14. Accessibility Requirements

Typography must support readable contrast, sufficient size, and clear hierarchy [cite: 3]. Never rely only on font weight, color, or size to communicate meaning [cite: 3].

---

# 15. Responsive Typography

- **Desktop:** Full hierarchy [cite: 3].
- **Tablet:** Maintain readability [cite: 3].
- **Mobile:** Avoid excessive scaling down; text must remain comfortable to read [cite: 3].

---

AI agents must [cite: 3]:

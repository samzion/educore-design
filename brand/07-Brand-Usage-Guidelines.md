# EduCore Brand Usage Guidelines

## 1. Purpose

This document establishes the definitive operational rules for applying the EduCore brand system across digital product interfaces, corporate websites, executive presentations, official documentation, marketing platforms, and future product extensions.

> **Brand Axiom:** Every EduCore touchpoint must feel unified, intentional, and structured. Whether an administrator logs into the web application, a teacher opens the mobile app, or a school board reviews an enterprise proposal, EduCore must project operational authority and institutional trust.

## 4. System Color Application Standard

Color must communicate utility and state resolution rather than decorative visual flare:

- **Brand Primary Navy (`#0F172A`):** Identity anchor, main navigation shells, key actionable primary buttons.
- **Neutral Canvas (`#F8FAFC`) / Text (`#0F172A`):** Dominates 80%+ of product interfaces to maximize scannability.
- **Semantic Feedback (Success/Warning/Error):** Strictly reserved for system state notifications, process validation, and data table chips.

## 7. Pre-Publication Brand Audit Checklist

Before publishing any marketing asset, document, or interface component, verify against this checklist:

- [ ] **Identity:** Approved logo lockup utilized with mandatory clear space.
- [ ] **Color:** Palette maps directly to approved design tokens with WCAG AA contrast.
- [ ] **Typography:** Standard font scales and weight hierarchies strictly applied.
- [ ] **Clarity:** Free of unnecessary visual decoration, low-contrast text, or non-standard icons.
- [ ] **Voice:** Communicates organized, high-performance operational authority.

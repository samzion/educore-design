- **Layout**: Welcome back, Administrator / Graceland International Academy / Quick Actions ([Add Student], [Add Staff], [Record Payment]), School Overview ([Students] [Staff] [Attendance] [Fees]), Attention Required (12 incomplete attendance records, 5 assessments awaiting approval, 23 outstanding payments), Academic Overview (Assessment completion, Result readiness), Recent Activity [cite: x].

---

## 6. Dashboard Sections

### Section 1: School Context
- **Purpose**: Provide immediate orientation [cite: x].
- **Display**: school name, current session, current term (e.g., 2026/2027 Academic Session / First Term) [cite: x].

### Section 2: Quick Actions
- **Purpose**: Allow common administrative tasks (e.g., Add Student, Create Staff Account, View Payments, Generate Report) [cite: x].
- **Rules**: Maximum 3-5 actions [cite: x].

### Section 3: School Overview
- **Purpose**: Provide operational snapshot [cite: x].
- **Metrics**: 
  - *Students*: Total Students, Active Students, New Admissions [cite: x]
  - *Attendance*: Today's Attendance Rate [cite: x]
  - *Finance*: Fees Collected, Outstanding Balance [cite: x]

### Section 4: Attention Required
- **Most important section**.
- **Purpose**: Highlight things requiring action (e.g., 8 assessments waiting approval, 15 students with incomplete records, 4 classes without attendance) [cite: x].
- Every item should be clickable [cite: x].

### Section 5: Operational Insights
- **Purpose**: Help administrators understand trends (e.g., Attendance trend: Improving +5%; Fee collection: Below expected target) [cite: x].

## 7. Student Management Experience

- **Goal**: Allow administrators to manage student lifecycle efficiently [cite: x].
- **Entry**: Sidebar $ightarrow$ Students [cite: x].
- **Student Directory**: Students / Manage student records / [+ Add Student] / Search students... / Filters (Class | Status | Session) / Data table (Admission No | Name | Class | Status | Action) [cite: x].
- **Student Creation Flow**: Use a guided workflow (Add Student $ightarrow$ Basic Information $ightarrow$ Guardian Information $ightarrow$ Enrollment Details $ightarrow$ Medical Information $ightarrow$ Confirmation $ightarrow$ Create) [cite: x] rather than a single overwhelming form [cite: x].
